# doon.today

A semi-curated, text-first calendar of things happening in Dehradun.

## MVP

- Answer **“What can I do in Dehradun today or this weekend?”**
- Stay close to BLR.today's calendar-first product philosophy.
- Use a restrained Doon editorial visual identity.
- Retain source provenance and freshness metadata on every event.
- Refresh source data every 8 hours (3x/day) via GitHub Actions.

## Initial source strategy

Primary: District, BookMyShow. Secondary: AllEvents, Townscript. Discovery: r/Dehradun and known local communities. Community-only events require stronger verification before publication.

## Stack

Astro + TypeScript + static event data + GitHub Actions + Netlify.
